# MOOC Java — exercícios de estudo

Minhas soluções e implementações locais dos exercícios de Java Programming I, da Universidade de Helsinque.

Os projetos estão organizados em `java-programming-i`, preservando os nomes dos exercícios, o código-fonte, os testes fornecidos pelo curso e os arquivos Maven.

Foram incluídos os exercícios das partes 1 a 4 e os três primeiros da parte 5, até `part05-Part05_03.Cube`. Os projetos posteriores ainda estavam como modelos e ficaram de fora. A presença de um exercício aqui não certifica que todos os testes do curso tenham sido aprovados.

## Executar

Abra a pasta de um exercício no TMCBeans/NetBeans. Cada exercício é um projeto Maven independente. Com Maven e JDK instalados, também é possível executar:

```sh
cd java-programming-i/part01-Part01_01.Sandbox
mvn test
```

Alguns testes usam dependências específicas do TMC, que o Maven pode precisar baixar. A compilação das classes principais usa JDK 11.
